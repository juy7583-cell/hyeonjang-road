## 제출 최종판
- 정지 차량 누락을 현재 영상 대조로 최대 8초 보완
- 같은 대기열 잔존 시 직전 점수 추정 유지, 근거 소멸 시 판단 보류
- 안전 100점 제거, 관측 상태 표시
- 4번 영상 3.75~9.75초 혼잡 유지(75~85점), 기본 영상 혼잡 0시점
- 세부 차종 분류는 실험 기능이며 기본 꺼짐

## 구성
앱 소스: src/. 실행 모델·샘플·라이브러리: runtime-assets.zip. Actions에서 압축을 해제하고 소스를 결합하여 테스트 후 Pages에 배포합니다. 검증 기록은 verification/, 상세 한계와 자료 출처는 src/MODEL_CARD.md에 있습니다.

점수는 과제용 규칙 지표이며 사고 확률·공인 안전등급이 아닙니다. 검증 영상에 맞춰 수정했으므로 해당 결과는 회귀 테스트이며 불특정 CCTV 정확도가 아닙니다.
